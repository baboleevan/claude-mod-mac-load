# claude-mod-mac-load

로컬 맥의 CPU·메모리 부하를 실시간으로 보여 주는 Claude Code mod(`mac-load`)입니다.
세션 옆에 창을 하나 띄워 두고, 고른 주기(기본 2초)마다 값을 다시 읽어 그립니다.

## 보여 주는 것

- **CPU**: 사용률 막대, 사용자·시스템·유휴 비율, 최근 추이 그래프
- **메모리**: 사용률 막대와 추이 그래프. 막대는 `memory_pressure`가 알려 주는 여유율을 기준으로 `100 - 여유율`을 그립니다.
- **부하 평균**: 1·5·15분 값과 코어 수
- **CPU 상위 프로세스**: CPU를 가장 많이 쓰는 5개와 각각의 메모리. 이름은 `top`이 16자에서 자르는 대신 `ps`로 전체 이름을 읽어 보여 줍니다(`com.apple.Virtualization.VirtualMachine`). 창이 좁아 한 줄에 다 안 들어가면 끝을 `…`로 줄입니다.
- **메모리 상위 프로세스**: 메모리를 가장 많이 쓰는 5개와 각각의 CPU. `top`을 한 번만 읽어 두 목록을 함께 뽑으므로 부하가 늘지 않습니다.

값은 macOS의 `iostat`, `top`, `ps`, `memory_pressure`, `sysctl` 출력에서 읽으므로 **macOS에서만** 동작합니다.

## 설치

Claude Code 터미널 세션의 프롬프트에서:

```
/plugin install mac-load --marketplace baboleevan/claude-mod-mac-load
```

셸에서:

```
claude plugin install mac-load --marketplace baboleevan/claude-mod-mac-load
```

데스크톱 앱에서는 프롬프트 상자 옆의 + 를 누르고 Plugins, Add marketplace에 `baboleevan/claude-mod-mac-load`를 넣은 뒤 Add plugin을 누릅니다.

처음에는 마켓플레이스를 추가할지 묻습니다. `y`로 답하고 범위(scope)를 고르면 `Installed mac-load.`가 보이고, 그 세션부터 바로 켜집니다.

## 사용

- 세션이 시작되면 창이 자동으로 열립니다.
- 터미널이 좁으면 자동으로 열린 창이 바로 보이지 않을 수 있습니다. 그럴 때나 창을 닫았을 때는 `/mac-load`를 입력하면 열립니다.
- 창은 세션이 켜져 있는 동안에만 값을 읽습니다. 세션을 닫으면 측정도 멈춥니다.

### 접기·펼치기

창 위쪽의 `▼ 접기` 버튼을 누르면 한 줄 요약(`CPU 27% · 메모리 40% · 부하 5.16`)만 남고, `▶ 펼치기`를 누르면 다시 펼쳐집니다. 창에 키보드가 있을 때는 `c`로도 누를 수 있습니다.
접어 두면 CPU를 가장 많이 쓰는 프로세스 목록 측정(`top`)을 멈추고 부하만 계속 잽니다.

### 닫기

창 위쪽의 `✕ 닫기` 버튼(창이나 띠에 키보드가 있을 때는 `x`)이나 `/mac-load close`로 닫습니다. 창은 닫히고, 띠는 치워집니다. 접은 모양과 한 줄로 줄어든 띠에도 버튼이 있습니다.
창은 Claude Code의 닫기 표시(×)나 ctrl+x 다음 x로도 닫을 수 있습니다. 다시 열려면 `/mac-load`(띠로는 `/mac-load band`)를 치세요.
닫아도 측정은 세션이 켜져 있는 동안 계속됩니다.

### 위치

창 위쪽의 "위치"에서 보여 줄 자리를 고릅니다.

- **오른쪽 창**(기본): Claude Code가 화면 환경에 따라 자리를 정합니다. 전체 화면 레이아웃에 터미널 폭이 110칸 이상이면 대화 오른쪽에 붙고, 그렇지 않으면 프롬프트 위에 놓입니다.
- **아래쪽 띠**: 프롬프트 바로 위의 띠로 그립니다. 터미널 폭과 상관없이 항상 아래쪽입니다. 고르면 창은 닫힙니다.
  - 띠는 프롬프트 위의 남는 자리만큼만 쓸 수 있어서 자리에 맞춰 모양이 바뀝니다. 약 30줄 이상이면 창과 같은 내용 전부, 10줄 이상이면 막대·그래프·부하 평균만(프로세스 목록은 접힘), 그보다 좁으면 한 줄 요약만 보입니다.
  - 띠를 잠시 치우려면 Claude Code의 띠 접기(`[-]` 또는 ctrl+x ctrl+a)를 쓰세요. 이 mod의 `▼ 접기`는 한 줄 요약으로 줄입니다.
  - **띠를 골랐는데 5초가 지나도 한 번도 그려지지 않으면**(이 화면에서는 띠가 안 보이는 경우) 창으로 자동으로 되돌리고 알림을 띄웁니다.
- 위치는 세션 안에서만 기억합니다. 새 세션은 다시 "오른쪽 창"으로 시작합니다.
- `/mac-load`는 늘 창을 엽니다(띠가 안 보일 때 돌아오는 길). `/mac-load band`는 아래쪽 띠로 옮기고, `/mac-load close`는 닫습니다.

### 갱신 주기

창 위쪽의 "갱신 주기"에서 **2초(기본) / 1초 / 0.5초**를 고릅니다(방향키로 옮기고 Enter).

- CPU·메모리·부하 평균은 이 주기마다 새로 읽습니다.
- **맥에서는 CPU를 1초보다 짧게 잴 수 없어서**(`iostat`·`top` 모두 최소 1초 단위) 0.5초를 골라도 실제 갱신은 약 1초입니다. 창에 실제 간격이 `실제 1.0초마다`처럼 보입니다.
- 프로세스 목록은 `top`이 한 번에 약 3초 걸려 주기와 상관없이 3초 남짓마다 갱신되고, 목록 옆에 몇 시 기준인지 표시됩니다.

## 개발

```
claude --plugin-dir <이 폴더>   # 폴더에서 바로 불러와 실행
claude plugin validate <이 폴더>
claude plugin test <이 폴더>    # hooks/*.test.ts(.tsx) 실행
```

- `hooks/register.tsx`: 명령 등록, 측정 주기, 화면 그리기
- `hooks/cadence.ts`: 갱신 주기 선택지와 다음 측정 시점 계산 (엔진에 의존하지 않음)
- `hooks/layout.ts`: 위치 선택지, 띠의 모양(전부·줄여서·한 줄) 고르기, 띠가 안 그려질 때 되돌리는 규칙 (엔진에 의존하지 않음)
- `hooks/names.ts`: `ps`로 프로세스 전체 이름을 읽고 자리에 맞게 줄이는 함수 (엔진에 의존하지 않음)
- `hooks/iostat.ts`: `iostat` 출력을 읽는 순수 함수 (엔진에 의존하지 않음)
- `hooks/top.ts`: `top`·`memory_pressure` 출력을 읽는 순수 함수 (엔진에 의존하지 않음)
- `types/index.d.ts`: 저장하는 값의 타입

## 알아 둘 점

- macOS 전용입니다. Linux·Windows에서는 측정에 실패했다는 문구가 보입니다.
- macOS의 `top`은 파일 캐시까지 "사용 중"으로 세어 메모리가 늘 가득 차 보입니다. 그래서 메모리 막대는 `top`의 사용량이 아니라 `memory_pressure`의 여유율을 쓰고, 여유율을 읽지 못할 때만 `top` 값으로 대신합니다.
- `top`은 프로세스를 훑는 데 한 번에 CPU를 코어 하나의 절반 넘게 씁니다. 접어 두면 이 부하가 사라집니다.
- CPU 사용률은 `iostat`이 주는 정수 퍼센트입니다.
- 화면 문구는 한국어입니다.
